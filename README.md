# MAKTO Engineer Kitchen — Mission 001

Minimal, responsive local-first engineering workspace prototype.

## Run
Open `index.html` in any modern browser. No dependencies or credentials required.

## Implemented
- Responsive navigation and project dashboard
- Explore / Solve / Engineer / Optimize project entry points
- Project creation and browser-local persistence
- Research workflow explanation
- JSON export of project memory
- HTML escaping for user-generated project content

## Not implemented yet
- Real AI agent orchestration or internet research
- CAD viewer, simulation, external file ingestion
- Authentication, shared database, GitHub sync, notifications

## Next milestones
1. Move to React/TypeScript with typed project schema.
2. Add server-side research agents with source citations and human approval gates.
3. Add 3D viewer (Three.js) and STEP/STL processing service.
4. Add persistent database, authentication, tests and deployment.

No existing ONDA repositories were modified.
